# SunFounder teaching examples

The original examples remain at `~/picrawler/examples` on the robot. PiBotPal's
Testing tab keeps the source filenames as a cross-reference, but implements its
own bounded exercises through the shared MCP controller. It does not import or
execute the original programs or use their motion tables or sound files.

Upstream: https://github.com/sunfounder/picrawler/tree/master/examples

SunFounder's programs retain their GPLv3 license and attribution. The previous
PiBotPal adapters are preserved in Git history with their original license
notices; this rewrite does not relicense those versions. `LICENSES/GPL-3.0.txt`
is retained for that historical/reference material.
